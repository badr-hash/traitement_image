# Introduction au traitement d’images

Travail pratique de vision artificielle en Python, avec un notebook et un script autonome utilisant NumPy et Matplotlib.

## Contenu

- [TP1.ipynb](TP1.ipynb) : notebook du travail pratique.
- [tp1_tout_en_un.py](tp1_tout_en_un.py) : script regroupant les exercices.
- [test1.jpg](test1.jpg) et [test2.jpg](test2.jpg) : images utilisées par le script.

## Exécution du script

```bash
python tp1_tout_en_un.py
```

Le script crée un environnement virtuel local `venv`, installe NumPy et Matplotlib via pip, puis se relance. Il requiert donc une connexion internet lors de l’installation. Si les fichiers image sont absents, le script contient des images de remplacement. Consultez le code avant exécution ; les instructions n’ont pas été testées dans un environnement neuf.
